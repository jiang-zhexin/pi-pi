# Pi ECNU

ECNU Chat provider extension for the [Pi](https://pi.dev) coding agent.

Registers the `ecnu` provider with **chat models** (`ecnu-max`, `ecnu-plus`) and **image generation/editing** (`ecnu-image`).

## Quick Start

### Installation

```bash
pi install npm:@zhexin/pi-ecnu
```

### Setup Your ECNU API Key

```bash
pi auth login ecnu
```
