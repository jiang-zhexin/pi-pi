# Pi AGY

Antigravity OAuth provider for the [Pi](https://pi.dev) coding agent.

## Quick start

```bash
pi install npm:@zhexin/pi-agy

pi auth login agy
```

## Usage

Install [`@zhexin/pi-usage`](../usage/README.md) and run `/usage agy` to show remaining 5-hour and weekly quota, with reset times.
